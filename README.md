# AI That Works plugins

The plugin catalog for AI That Works members. Installing a plugin needs a member licence key.

## Add the catalog

Claude Code:

```
claude plugin marketplace add zellwk/aithatworks-plugins
claude plugin install atw@aithatworks
```

Codex:

```
codex plugin marketplace add zellwk/aithatworks-plugins
codex plugin add atw@aithatworks
```

Members get a setup prompt with their key that runs these steps for them.
